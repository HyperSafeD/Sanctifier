## Critical Issues Found

### 🔴 HIGH: Scoop Binary Array Bug

**File**: `scoop/sanctifier.json`

The `bin` array only maps the AMD64 binary, not ARM64:

```json
"bin": [
  [
    "sanctifier-windows-amd64.exe",
    "sanctifier"
  ]
]
```

**Impact**: ARM64 Windows users won't be able to run `sanctifier` after installation

**Recommendation**: Scoop doesn't support architecture-specific bin arrays in the same manifest. Two options:
1. Split into two separate manifests (sanctifier-amd64, sanctifier-arm64)
2. Use a wrapper script that detects architecture

**Proposed Fix**: Update to use architecture-specific bin mapping (see fixes below)
